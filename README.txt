PROJECT ZERO 0.9.3 - GITHUB AUTO-UPDATER

WHAT THIS BUILD DOES
- Checks the public GitHub Releases feed when the installed Windows app starts.
- Shows UPDATE NOW and LATER when a newer stable release exists.
- LATER starts the currently installed version. The update prompt appears again on the next launch.
- UPDATE NOW downloads the update and displays download progress.
- After download, RESTART AND INSTALL applies the NSIS update and restarts the game.
- A failed download leaves the currently installed version in place.
- The updater does not delete Electron userData or browser localStorage, where the current Story Mode save is stored.

CURRENT VERSION
The game HTML identifies itself as 0.9.3. package.json has been aligned to 0.9.3.

IMPORTANT: SET UP THE FIRST GITHUB RELEASE
The updater cannot find updates until a GitHub Release exists and includes the installer metadata generated by electron-builder (latest.yml and the installer files).
Repository: https://github.com/charliepieper0-code/ProjectZero

BUILD ON WINDOWS
1. Install Node.js LTS.
2. Open this project folder in Command Prompt.
3. Run: npm install
4. Run: npm start (development test; updater checks are disabled in development mode).
5. Run: npm run dist
6. The Windows installer will be created in the dist folder.

PUBLISH A RELEASE
To publish through electron-builder, create a GitHub Personal Access Token with permission to publish releases to the ProjectZero repository. Do not paste the token into source files or share it in chat.
In PowerShell for the current terminal only:
  $env:GH_TOKEN = 'YOUR_GITHUB_TOKEN'
Then run:
  npm run publish

The first published installer is the baseline installation. For every future update, increase the version in package.json (for example 0.9.4), then run npm run publish again. Do not reuse a version number for a different build.

SAVE DATA
Do not delete the game's user data folder when installing or updating. The updater does not intentionally clear saves. Keep a backup of important campaign saves before testing a first release.

NOTES
- Updates are checked only in packaged builds. npm start intentionally opens the game directly.
- The GitHub repository must be public, or the updater needs authenticated/private-release configuration.
- The current source package has no separate asset folder; the game UI and game content are in index.html, and Three.js is installed through npm.
